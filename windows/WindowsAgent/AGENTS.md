# 内置 Windows Agent 规则

1. 本目录只提供编译进 `MenoClipboard.exe` 的内部库，不得增加独立 EXE、独立托盘或独立启动项。
2. 端口 45900、`_meno-agent._tcp.local.`、MCP 路径、17项工具、配置目录、任务数据和 Windows 凭据名称属于现有兼容边界。
3. Agent 必须运行在与鼠标、剪贴板和 MENO 网络主路径隔离的后台运行时；任何 Agent 故障都只能降级 Agent 自身。
4. 截图工作进程只能复用同一个 `MenoClipboard.exe`，不得产生第二个可分发程序或托盘。
5. 系统范围保持只读；项目写入和项目命令必须继续受登记根目录、哈希校验、程序白名单和自修改保护约束。
6. 本目录通过根目录验证和 Release 入口交付，不单独安装、启动或发布。
